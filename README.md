# Home Assistant Integration - Bordeaux Métropole - Pont Chaban-Delmas

Intégration permettant de suivre l'état et les prévisions de fermeture du pont Chaban-Delmas (Bordeaux Métropole).

## Installation

Aucune clé n'est nécessaire. Ajoutez l'intégration depuis **Paramètres > Appareils et services > Ajouter une intégration > Pont Chaban-Delmas**.

[Dataset](https://datahub.bordeaux-metropole.fr/explore/dataset/previsions_pont_chaban/table/) source des prévisions de fermeture.
